# Limitaciones e incertidumbres

- El Ruleset DEMO existe para probar software; no es una prescripción basada en evidencia.
- `1.0.0-candidate` no está ACTIVE. Requiere revisión por un preparador cualificado, revisión clínica de reglas Safety y pruebas con usuarios.
- La literatura específica de escalada es heterogénea y no justifica una dosis universal por nivel, sexo, edad o modalidad.
- Los umbrales de experiencia, fatiga, adherencia, dolor, progreso y reevaluación están etiquetados como consenso, heurística o precaución.
- La entrada de dolor es autodeclarada; el sistema no diagnostica ni decide retorno deportivo.
- La disponibilidad de equipo en el MVP usa un equipo principal y una bandera de bandas en el formulario; la tabla normalizada permite ampliarlo.
- La planificación distribuye por menor tiempo acumulado y presupuesto. Las incompatibilidades complejas entre estímulos están modeladas como reglas ampliables, pero no forman un optimizador global.
- Excel está diseñado para un usuario a la vez; no ofrece transacciones multiusuario ni control de concurrencia.
- Importar/exportar Rulesets se entrega como paquetes CSV versionados y constructor reproducible; la interfaz VBA muestra el flujo, pero no implementa todavía un selector de carpetas con copia automática.
- Las hojas de dashboard iniciales son funcionales pero deliberadamente sobrias; no contienen analítica avanzada ni gráficos longitudinales hasta acumular historial real.
- El libro generado contiene un plan DEMO de prueba integral, claramente asociado a `0.1.0-demo`.
