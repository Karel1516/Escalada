# Guía de usuario

1. Inicia la aplicación desde el acceso directo o con `entrenamiento-escalada` en desarrollo.
2. Crea el perfil, selecciónalo en Inicio e indica disponibilidad, equipo, objetivo y limitaciones actuales.
3. Usa DEMO únicamente para explorar el funcionamiento. Un ruleset `RESEARCH` no se activa por defecto.
4. Revisa advertencias y la versión antes de generar el plan.
5. En “Historial y trazabilidad” consulta RuleID y valores; en “Modo técnico / Debug”, el snapshot canónico.
6. Registra cada sesión; un segundo registro para la misma sesión es rechazado.
7. En Configuración puedes validar el ruleset incluido, importar un ZIP validado y exportar/restaurar copias.

La aplicación no diagnostica lesiones. Si existe lesión, dolor preocupante o empeoramiento, detén la actividad correspondiente y consulta a un profesional cualificado.
